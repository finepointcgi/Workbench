Try Workbench on your computer in two minutes

You need Docker and Git. This runs Workbench with sample data so you can click through time, billing, the Plan and the Costpoint importer before you decide anything.

Try the live demoSee pricing

Step 1: try it

Run these four commands in a terminal. The first build takes a few minutes.

git clone https://github.com/finepointcgi/workbench.git
cd workbench
docker build --target demo -t workbench-demo .
docker run --rm -p 8080:8080 workbench-demo

Open http://localhost:8080 and sign in as Dana Lee, the administrator. If something else on your machine already uses port 8080, change the first number, for example -p 8090:8080.

This is for trying only. Anyone who can reach the page can sign in as any sample user, and the data is sample data that resets every night. Do not enter real company information.

Step 2: run it for real

A real install runs on one Linux server with PostgreSQL, behind HTTPS, with people signing in through your identity provider (Microsoft Entra ID, Google, Okta or any OpenID Connect provider). The repository includes a complete single-server example with the database, the migration step, the web host and a TLS proxy.

  • Point a DNS name at a Linux server with Docker.
  • Run the script that creates your secrets, and fill in your identity provider details.
  • Start it with docker compose -f docker-compose.prod.yml up -d --build.
  • Sign in as the administrator and follow the setup checklist.

If you would rather not run a server, we can host it for you on the Business plan.

Step 3: bring your data

Under Setup, Migration there are importers for Costpoint, Smartsheet and Unanet, with a checklist for importing each kind of data in order, checking the totals and running a month in parallel. Try it on a copy of your data first.

Before you start

  • The two-minute trial uses sample data and is not secure enough for real information.
  • A real installation needs HTTPS and an identity provider; the example setup expects you to supply both.
  • A one-command setup for a real install is not built yet.

Questions

Do I need to know how to run a server?

For the two-minute trial, no. For a real installation you need someone comfortable with Linux servers and Docker, or you can ask us to host it.

Does it cost anything to run?

The software is free in the Community edition. You pay for your own server, which can be a small cloud machine. Business features are $10 per person per month.

Can I try it without Docker?

Yes, but it needs the .NET 10 SDK. The steps are in the project README.

Price
