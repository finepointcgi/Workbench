A scheduling tool that knows what the project costs

Workbench schedules projects with the features contract managers expect (dependencies, critical path, baselines and earned value) and connects them to the hours people actually charge and the invoices you send.

Scheduling features

  • Gantt chart with finish-to-start, start-to-start, finish-to-finish and start-to-finish links, with lead and lag.
  • Task constraints, project calendars, deadlines and milestones.
  • Critical path and float, and up to 11 saved baselines to compare against.
  • Status date, percent complete and a "try changes" mode to test a what-if before committing.
  • Earned value (CPI and SPI) and resource allocation and utilisation.
  • Import and export of MS Project XML.

Connected to the money

A schedule in a standalone tool is a guess. Here, the same project holds the budget, the hours entered against it and the funding on the contract, so status reports and earned value start from real numbers.

Where MS Project is ahead today

  • Resource leveling, task types such as fixed units and fixed work, effort-driven scheduling, split and recurring tasks, subprojects with cross-project links, and views such as the network diagram and task usage are not in Workbench yet.
  • Workbench cannot open .mpp files; it uses XML.
  • If you plan very large programmes with heavy resource leveling, MS Project is still the stronger planner.

Questions

Can I open my MS Project files?

Workbench reads and writes MS Project XML. It does not read .mpp files directly, so save your file as XML from MS Project first.

Does it support the critical path and baselines?

Yes. It shows the critical path and float, and keeps up to 11 baselines.
