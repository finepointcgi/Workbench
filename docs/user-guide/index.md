# User guide

How to do your everyday work in Workbench. Pages are grouped the way the menu is.

## My work (everyone)

| Page | What you do there |
| --- | --- |
| [Timesheets](time.md) | Record hours every day, use the timer, certify and submit, correct a past day |
| [Expenses, receipts and travel](expenses.md) | Request a trip, file an expense report with receipts and per diem, clear card charges |
| [Leave](leave.md) | See balances, request time off, subscribe to a calendar feed |
| [Purchase requests and receiving](requisitions.md) | Ask to buy something, receive what arrives |

## Approving and managing

| Page | What you do there |
| --- | --- |
| [Approvals](approvals.md) | Approve, return or reject timesheets, expenses, purchases, bills and plans; delegate while away |
| [Projects and the project page](projects.md) | See a project's health, money, team and costs; start a new project |
| [Planning a project](project-plan.md) | Build the WBS and schedule, assign people, submit the plan for approval |
| [Resourcing](resourcing.md) | Staff people, see the heat map and utilization, find people for unstaffed budget |
| [Project costs (ODCs)](project-costs.md) | Enter vendor invoices and other non-labor costs against a project |
| [Proposal pricing](pricing.md) | Price a bid from your own rates and hand a won price to the contract |

## Shared work

| Page | What you do there |
| --- | --- |
| [Sheets](sheets.md) | Plans and trackers as a grid, board, calendar or Gantt chart, with automations and forms |
| [Dashboards](dashboards.md) | Charts and numbers from your sheets on one page |
| [People and HR](people.md) | The directory and org chart, your profile and benefits; HR administration |
| [Business development](business-development.md) | Pipeline, opportunities, accounts and contacts, forecast and win/loss |
| [Reports](reports.md) | Standard government-contractor reports, saved reports and the report writer |

Finance, materials and administration have their own guides: [Finance](../finance/index.md),
[Materials](../materials/index.md) and [Admin](../admin-guide/index.md).
