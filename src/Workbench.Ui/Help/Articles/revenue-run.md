Revenue is recorded when it's earned, not when it's billed ([revenue recognition](term:revenue-recognition)). Each project has a method: for example [percent complete](term:percent-complete) (cost to cost), T&M as billed, or FFP milestones.

## Before the run

- Project managers submit their estimates ([EAC](term:eac)) in **Revenue estimates**; Finance approves them. Projects without a current estimate are flagged.
- Record deliveries for milestone or units-delivered projects (**Record delivery**).
- Approved time and costs for the month should be posted.

## Run it

1. Open **Finance › Revenue & compliance › Revenue** and pick the period.
2. Review each project's revenue to date, this period's amount and the difference from billing (unbilled or billed in excess).
3. Select **Post revenue run**. It posts one journal entry per project.

If something was wrong, **Reverse** the run, fix the cause and post it again. The revenue run is one of the month-end checks.
