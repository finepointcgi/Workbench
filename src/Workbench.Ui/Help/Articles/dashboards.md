A dashboard brings numbers and charts from your sheets together on one page.

## Create one

1. Open **Dashboards** and create a new dashboard. Give it a name and, if your team should see it, put it in your team's workspace.
2. Add widgets: a number (for example "Open risks"), a chart (counts by status), a list of rows, or a note.
3. Pick the sheet and columns each widget uses. Arrange and resize them as you like.

## Sharing

A dashboard in a workspace is visible to that workspace's members. Only its owner (or an administrator) can change it. Widgets never show more than you could see on the sheet itself, so a column hidden from someone stays hidden on the dashboard too.
