Closing a month locks it: no more postings, and no time or expense changes dated in it. Work through **Finance › Accounting › Period close**.

## Before you start

- Remind people to submit timesheets and expense reports. Your home page lists missing ones.
- Make sure approvers have cleared the **Approvals** inbox.

## The checklist

Pick the period. Each check shows a tick or what's left to do, with a link to fix it.

1. **Time and expenses decided**: every timesheet and ODC in the period is approved or rejected.
2. **Everything posted**: select **Post backlog** to post anything approved but not yet in the ledger.
3. **Payables**: bills for the month entered and posted ([Pay vendor bills](help:paying-bills)).
4. **Payroll** posted for each pay date in the month.
5. **Depreciation** run for the month.
6. **Indirect cost allocation** run, so projects carry their [fringe](term:fringe), [overhead](term:overhead) and [G&A](term:ga).
7. **Revenue run** posted ([Run revenue recognition](help:revenue-run)).
8. **Unbilled accrual** posted from Billing.
9. **Bank reconciliation** completed for each account ([Reconcile a bank account](help:bank-reconciliation)).
10. **Trial balance balances.**

When everything passes, select **Close** with the period's name.

## Reopening

If you must change a closed month, select **Reopen period** and give a reason. It's recorded in the audit log. Make the change, then close it again.

> [!NOTE]
> Reports (**Reports › Financial statements**) can be run for any period, open or closed.
